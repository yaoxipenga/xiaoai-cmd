💡 原理与已知限制

和现有两个插件的区别：「远程呼唤」的文字模式走 mibrain/text_to_speech，只是让音箱朗读文字； 「小爱语音助手」是在监听小爱已识别出来的对话文本。两者都不会让小爱执行一条新指令。

本插件的执行通道：优先走 MIoT 官方动作 5-4 execute-text-directive（siid=5, aiid=4）， 效果等同直接对小爱说出这句话，还能勾选静默执行；若设备没有 miotDID 或该动作被拒，再回退到云端 mibrain/ai_service（{tts:1, nlp:1, nlp_text:"…"}）。两条都不需要麦克风、不需要喊唤醒词。

凭据复用：设备列表、停止播放、音量、播报都通过宿主 /api/v1/jsplugin/miot/* 复用官方插件的登录态； 云端两条指令通道所需的小米账号凭据，则由本插件在本机读取「智能音箱」插件已保存的账号文件自动复用 —— 每次执行都会重新读取，因此官方插件自动刷新 token 后无需在这里做任何操作。

限制：不同机型 / 固件对文本指令动作的开放程度不一致，老款（如小爱音箱 mini）可能返回非 0 错误码； 「接听 / 挂断电话」还取决于音箱本身是否绑定通话功能。日志会逐条记录 HTTP 状态与云端返回码，装上试一次即可确认。
若两条云端通道在您的机型上都被拒绝，可勾选「执行前停止播放」+ 用「仅播报」让音箱提示一句，再正常语音下达指令； 或在米家 App 里为该音箱建立「手动场景」并用小爱口令触发。
